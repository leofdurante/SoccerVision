Pipeline — upload to read-out
1  Samplevideo_processor.extract_frames() — OpenCV, 5 fps, seeks to a requested window. Timestamps stay absolute (original video clock).
2  Detect + trackcv/tracker.py — one Ultralytics model.track() call: YOLOv8n (COCO person/sports ball) + ByteTrack, persist=True, imgsz=1280, conf=0.25.
3  FilterDetections rejected when their feet are off turf (HSV grass mask). Post-pass drops static-overlay tracks — long-lived + high in frame + near-zero movement.
4  Team splitcv/team_classifier.py — k-means over shirt-region colour on cached per-track crops, so a track gets one team, not a per-frame flicker.
5  Mapcv/field_mapper.py — cv2.getPerspectiveTransform. Currently identity-cornered, so it is a linear rescale, not a registration. See limits below.
6  Analyticsanalytics/ — width, depth, avg spacing, compactness, defensive line height, third occupancy, zone overloads, events.
7  Read-outservices/ai_analyst.py — Anthropic Messages API over the structured stats only, never frames. Deterministic rule-based fallback if the key is absent or the call fails.

Numbers we can defend
Detection6.0 → 12.3 players/frame. Lever was imgsz 640→1280, not the model — a player is ~30 px tall at native res. Cost: 21 → 72 ms/frame.
Ablation grid640/.40 = 6.0 · 640/.25 = 8.2 · 1280/.40 = 8.5 · 1280/.25 = 12.3
Tracking374 → 180 ids for ~22 players over 2 min. Median track 5 → 12 frames. Single-frame tracks 66 → 12.
Tracker sweep150 real frames. defaults 106 ids/659 det → tuned 55 ids/801 det. Winning config in cv/trackers/soccer_bytetrack.yaml.
Ball0 → 57 detections in a 2-min window — upscaling put it over the detector’s floor. Below 25 detections we withhold possession rather than print a number.
Throughput600 sampled frames (2 min of play) in ~60 s, CPU-only, no GPU in the loop.
Tracker config — and why each value
match_thresh0.8 → 0.95. Inter-frame displacement is only ~8% of a box height, so a missed match costs far more than a loose one.
fuse_scoretrue → false. Folding confidence into match cost penalises the weak-but-real detections that matter at this resolution — worth ~a third of tracked detections.
new_track_thresh0.25 → 0.6. A flicker now has to be genuinely confident before it becomes a new player. This is what stopped the id explosion.
track_buffer30 → 60. At 5 fps that is 12 s of tolerance, so a briefly occluded player keeps their identity.
